# Projeto Integrador - 3° Semestre  
**Curso:** Engenharia de Software  
**Instituição:** PUC-Campinas  

## Descrição do Projeto  
Este repositório contém o desenvolvimento do Projeto Integrador do 3° semestre do curso de Engenharia de Software. O objetivo do projeto é integrar conhecimentos adquiridos nas disciplinas do semestre, promovendo a aplicação prática em um contexto real.  

## Objetivos  
- Desenvolver um aplicativo funcional e responsivo.  
- Implementar uma solução web eficiente e escalável.  
- Aplicar técnicas de criptografia para garantir a segurança dos dados.
